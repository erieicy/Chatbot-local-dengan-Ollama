# Chatbot Ai

*CARA MENGGUNAKAN CHATBOT AI LOKAL*

1. Download AI open source, (Disini saya menggunakan ollama),
link: https://ollama.com/download/windows 

2. Buka Terminal dan copy paste ini "pip install ollama"

3. Copy paste "ollama serve" diterminal

4. lalu copy paste "ollama list"

5. jika kosong, download AI lokal dahulu, saya menggunakan llama3.2:1b , jadi di Terminal copy paste "ollama run llama3.2:1b"

6. Tunggu, dan coba lagi yang no 4, jika ada, bisa langsung digunakan diterminal ataupun digunakan untuk Project

Jika menggunakan AI sebagai website, gunakan "pip install fastapi uvicorn ollamadi" Diterminal VScode 
lalu ketika sudah, gunakan Komen ini diterminal "uvicorn <nama file py>:app --reload" di terminal untuk menyalakan backend, karna saya menggunakan nama chat py, jadi Komennya menjadi 
" uvicorn chat:app --reload "

~ *AI Ini hanya dapat digunakan untuk pekerja ringan ataupun Project ringan Tanpa Token AI dan Gratis*~
